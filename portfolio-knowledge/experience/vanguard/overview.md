## Overview
During my internship at Vanguard Financial, I worked as a Data Analyst Intern supporting financial data collection, reporting, dashboard creation, and data process improvement. My work focused on helping the accounting and reporting teams organize financial data, improve weekly reporting workflows, and make key business metrics easier to access through dashboards and automated data cleaning.

A major part of my role involved improving SQL queries, automating data cleaning with Python, and building dashboards in Power BI and Tableau. This helped reduce manual reporting work, improve the accuracy of financial datasets, and make reports more useful for internal decision-making.

- Collected, cleaned, and analyzed financial data used for reporting and auditing support.
- Worked with accounting and business teams to understand reporting requirements.
- Improved SQL queries used for data extraction and weekly reporting.
- Automated repetitive data cleaning and processing tasks using Python.
- Built dashboards in Power BI and Tableau to visualize financial and business performance metrics.
- Created structured reports to help teams identify trends and review key financial information.
- Reduced manual spreadsheet work by improving data workflows.
- Validated data to ensure reports were accurate, consistent, and reliable.
- Helped reduce the need for repeated ad-hoc reporting by making dashboard data easier to access.
- Used Excel for data organization, review, calculations, and reporting support.

## Projects / Work Completed

### SQL Query Optimization for Financial Reports
Improved SQL queries used to extract financial and reporting data. The goal was to make recurring reports faster, more reliable, and easier to generate.

This involved reviewing existing queries, identifying slow or repetitive parts, improving filtering logic, and making sure the extracted data matched reporting requirements.

### Python Data Cleaning Automation
Created Python automation scripts to clean and process financial datasets. These scripts helped reduce manual work that would normally be done in Excel.

The automation handled repetitive tasks such as formatting data, removing inconsistencies, preparing datasets for reporting, and improving accuracy before the data was used in dashboards or weekly reports.

### Power BI Dashboard Development
Built Power BI dashboards to display key financial and business metrics in a more visual and accessible way. These dashboards helped internal users understand trends without needing to manually request or create separate reports each time.

The dashboards made it easier to track important values, compare periods, and review business performance.

### Tableau Dashboard Development
Created Tableau dashboards for financial reporting and performance tracking. The dashboards helped present data in a cleaner and more interactive format for internal review.

This work helped improve report usage because users could access insights directly from dashboards instead of relying only on static spreadsheets.

### Weekly Reporting Support
Supported weekly reporting workflows by preparing cleaned datasets, validating extracted data, and making sure reports were ready for internal use.

This included working with Excel, SQL outputs, and dashboard-ready datasets to support the accounting and reporting teams.

### Financial Auditing and Reporting Support
Worked with the accounting team to support data collection, analysis, and reporting for financial auditing and internal reporting needs.

This helped ensure that financial information was organized, accurate, and easier to review.
