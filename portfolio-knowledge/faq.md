What project best shows my AI or machine learning experience?

My RAG-powered portfolio chatbot is the clearest end-to-end AI product story because it combines retrieval, language models, and my own content. Document Scanner is my strongest computer vision and classical ML-adjacent build, with OpenCV pipelines for document detection, transforms, and text extraction.

My fourth-year engineering design capstone across COE70A and COE70B was Chat with NAO, a social NAO humanoid robot system. Our team split work between the robot running NAOqi in Python 2 and laptop-side Flask services in Python 3. The robot used a state machine for idle, conversation, facial recognition, and listen-and-dance modes, and talked to the laptop over the local network with HTTP, JSON, audio, and camera images. On the AI side I integrated OpenAI and ChatGPT for spoken conversation and for choosing dance routines, used Google speech-to-text for voice input, wired in the AudD API for song recognition, and built facial recognition with OpenCV, dlib, and the face_recognition library so the robot could greet known users and register new ones in a session. That project is my best example of shipping multimodal AI on real hardware with latency, lighting, battery, and network constraints, not only notebooks or pure web apps.

I also treat my other AI-integrated systems and coursework in machine learning, NLP, and intelligent systems as part of the same AI thread.

What project best shows my cloud experience?

My best cloud story is from COE892 Distributed and Cloud Computing. In Labs 4 and 5 I built a FastAPI minefield rover control server with REST endpoints for the map, mines, and rovers, WebSockets for interactive step-by-step rover control, and a small browser operator UI in HTML, CSS, and JavaScript. Once it worked locally I containerized it with Docker and deployed the image to Microsoft Azure using Azure Container Registry and Azure Web App for Containers, which is where I really practiced packaging, ports, repeatable environments, and running the same app in the cloud as on my machine.

The same course’s capstone was our Smart Parking System, a distributed web application with five FastAPI microservices including an API gateway, parking, sensor simulation, reservations, and occupancy-based pricing, plus a React and Vite frontend. We deployed the frontend to GitHub Pages with a GitHub Actions CI/CD workflow and used a Cloudflare HTTPS tunnel so the hosted frontend could call the backends without mixed-content issues while services still ran on our development machines. Together Labs 4 and 5 and that project show Docker and Azure deployment, microservices and gateway design, CI/CD to GitHub Pages, and secure-feeling connectivity between hosted clients and backend services.
