# Portfolio Knowledge Base

These markdown files are the source of truth for the future RAG-powered portfolio chatbot.

The chatbot should answer questions only from the content in this folder. It should not invent information, infer missing details, or add project, resume, skill, experience, course, or personal background details that are not written here.

Keep each file clean, factual, and easy to chunk for embeddings and vector search.

## Structure

- `about-me.md`
- `resume.md`
- `skills.md`
- `faq.md`
- `projects/`
- `experience/`
- `courses/`

## Personal Projects

The `projects/` folder should contain only personal projects.

- `projects/breakeven.md`
- `projects/nao-robot.md`
- `projects/document-scanner.md`
- `projects/smart-parking-system.md`
- `projects/football-pickems.md`
- `projects/rag-portfolio-chatbot.md`

## Experience

The `experience/` folder should contain work experience, internship experience, and role-specific accomplishments.

- `experience/ministry-of-transportation/overview.md`
- `experience/vanguard/overview.md`

## Courses

The `courses/` folder should contain course-specific files. Each course file should include the theory learned, lab work completed, tools used, and skills demonstrated.
